MASTER ENGINEERING JOURNAL, ERROR LOG & INTERVIEW GUIDE

1. EXECUTIVE SUMMARY & BUSINESS SCENARIO
----------------------------------------------------------------------
- Business Requirement: A major online sports betting platform expanding into a 
  newly regulated market needed an enterprise-grade hybrid cloud architecture.
- Architecture Challenge: Bridging secure private databases with public cloud workloads 
  with low latency, enterprise security, and automated IaC across all 4 project phases.


2. ARCHITECTURE BREAKDOWN ACROSS 4 PHASES
----------------------------------------------------------------------
- Phase 1: Private Infrastructure & Database Tier (Docker PostgreSQL & Ansible provisioning).
- Phase 2: Secure Migration Ledger & Network Simulation (Python export scripts & VPC simulation).
- Phase 3: Modular Terraform Public Cloud Landing Zone (AWS VPC modules & subnets).
- Phase 4: Configuration Management & System Hardening (Ansible security & kernel optimization).


3. COMPLETE ERROR LOG, MISTAKES & TROUBLESHOOTING GUIDE
----------------------------------------------------------------------
- Error 1: GitHub File Size Limit Rejection (GH001) due to compiled Terraform `.terraform/` provider caches.
  * Resolution: Added strict `.gitignore` rules, removed cached folders from index (`git rm -r --cached`), and pushed clean code.
- Error 2: Standalone `docker-compose` binary not found on modern Ubuntu.
  * Resolution: Switched command syntax to the native Docker plugin standard (`docker compose up -d`).
- Error 3: Ansible local become timeout / interactive authentication prompts.
  * Resolution: Configured a dedicated local inventory file (`ansible/hosts.ini`) with `ansible_connection=local`.


4. INTERVIEW PREPARATION TALKING POINTS
----------------------------------------------------------------------
- "How did you design a hybrid cloud network without paid enterprise gear?"
  * Answer: Simulated private virtualization and routing using Docker networks, local PostgreSQL instances, and Python cloud simulation scripts.
- "How do you manage Git hygiene with IaC tools?"
  * Answer: Ensured strict `.gitignore` rules for provider caches and `.tfstate` files while keeping configuration code lightweight and reproducible.
